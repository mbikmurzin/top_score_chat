# TopScore для чатов

Веб-платформа для импорта XLSX/CSV, объединения данных чат-воронок и расчёта маркетинговых показателей. Интерфейс включает разделы «Загрузка данных», «РК и траты», «Сводная по РК» и «TopScore».

## Локальный запуск

Требуется Python 3.11 или новее.

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload
```

После запуска откройте http://127.0.0.1:8000.

Локальная база создаётся в `data/topscore.db`, загруженные исходники сохраняются в `data/uploads`. Каталог `data`, Excel/CSV-файлы и локальные скриншоты исключены из Git, поскольку могут содержать персональные данные.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

## Развёртывание

Приложение построено на FastAPI и запускается командой:

```text
uvicorn app:app --host 0.0.0.0 --port <PORT>
```

Для рабочего размещения необходимы постоянный диск или внешняя база данных: без них загруженные таблицы, история фактов и справочник MAX ID будут потеряны при перезапуске сервера.

Streamlit Community Cloud напрямую запускает только Streamlit-приложения. Для размещения этого проекта там потребуется отдельная Streamlit-версия интерфейса и постоянное внешнее хранилище данных.
